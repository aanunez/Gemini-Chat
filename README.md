# Gemini Integrated Browser

A small VS Code extension that opens Gemini in VS Code's built-in Integrated Browser.

## Use

Select the **Gemini** icon in the Activity Bar to open Gemini in VS Code's Integrated Browser in the editor area. Sign in and chat as usual.

You can also run **Gemini: Open in Integrated Browser** from the Command Palette.

## Run locally

Open this folder in VS Code and press **F5** to launch an Extension Development Host. The extension has no external dependencies or build step.
